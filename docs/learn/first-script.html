Write your first script

Beginner10 min

Scripts are C# files that give objects behaviour. Strata compiles them while the editor is open, so you can change a script, save it and see the result straight away.

1Make a project and a cube

In Strata Hub choose New project, 3D game and Empty 3D. In the editor open GameObject › 3D Object › Cube. A cube appears in the scene and in the Hierarchy.

2Create a script

In the Project panel click + Create and choose C# Script. Name it Spinner. Double-click the new file to open it in your code editor (you can choose the editor in the Hub under Settings).

3Write the code

Replace everything in the file with this:

using System.Numerics;
using Strata;

public class Spinner : MonoBehaviour
{
    public float Speed = 90f;      // degrees per second

    public override void Update()
    {
        Transform3D.Rotate(new Vector3(0, Speed * Time.DeltaTime, 0));
    }
}

Every script is a class that inherits MonoBehaviour. Update() runs once every frame. Time.DeltaTime is the time since the last frame, so the cube turns the same speed on fast and slow computers.

Save the file. In the editor the top right shows Compiling scripts and then Scripts OK. If you made a mistake the Console shows the error with the line number.

4Add the script to the cube

Select the Cube. In the Inspector click Add Component, type Spinner and click it. Because Speed is a public field it shows up in the Inspector. Press Play and the cube spins. Change Speed while the game runs to see it change, then stop and set the value you like.

5Move with the keyboard

Add these two lines inside Update(), after the rotate line:

float x = Input.GetAxis("Horizontal");               // A and D, arrow keys, gamepad stick
Transform3D.Translate(new Vector3(x * 3f * Time.DeltaTime, 0, 0));

Save, press Play, click in the Game view and press A and D. The cube spins and slides sideways.

6Show a message

Debug.Log writes to the Console tab next to the Project tab:

public override void Start()
{
    Debug.Log("The cube is ready!");
}

Start() runs once when the game starts. Add it to the class, save, press Play and look at the Console.
